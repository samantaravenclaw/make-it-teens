# Простой шаблон лендинга

Откройте `index.html` в браузере. Шаблон сделан без сборки и сторонних библиотек.

## Структура страницы

1. **Шапка** — название проекта, переходы к разделам и кнопка действия.
2. **Первый экран** — кому и какую задачу решает продукт; главная кнопка.
3. **Преимущества** — три конкретных результата для посетителя.
4. **Знакомые лица** — ученики, выпускники, капитаны команды и преподаватели Когтеврана с фотографиями или именными значками и ссылками на официальные материалы.
5. **О продукте** — кратко объясняет подход и помогает снять сомнения.
6. **Гимн Хогвартса** — короткий фрагмент песни, пояснение о мелодии и авторский пересказ качеств факультетов.
7. **Форма** — простой следующий шаг с минимумом полей.
8. **Подвал** — контакты и служебная информация.

## Файлы

- `index.html` — содержание и смысловые блоки страницы. Ищите комментарии `1.`–`8.`.
- `style.css` — внешний вид. В начале файла находятся главные цвета; внизу — правила для узких экранов.
- `script.js` — пример реакции формы. Сейчас она ничего никуда не отправляет.
- `assets/` — фон, портреты, иллюстрации гостиной и статичный кадр орла; CSS задаёт частые взмахи во время полёта и один взмах в минуту после посадки. Портреты персонажей загружаются с официального сайта Harry Potter. Для персонажей без отдельного официального портрета в галерее показаны именные значки.

## Как адаптировать

1. Замените `ТВОЙ БРЕНД`, заголовки и подсказки на информацию о своём продукте.
2. Оставьте одну главную цель страницы и повторите призыв к ней в шапке и форме.
3. Для каждого преимущества укажите результат, который важен клиенту.
4. Поменяйте цвета в `:root` в `style.css`.
5. Перед публикацией подключите форму к сервису заявок, замените пример контактного адреса и настройте текст согласия на обработку данных.

Адаптивность: сетка перестраивается в одну колонку на телефонах. HTML использует семантические секции, подписи полей формы и описания для вспомогательных технологий.
